# 축제로 (Festival-ro)

> 축제로 시작하는 주말 코스. 1박 2일 일정을 자동으로 만들어주는 여행 큐레이션 앱.

🚧 **개발 중인 포트폴리오 프로젝트입니다.** 구현 코드는 비공개로 유지하고 있으며, 이 저장소는 프로젝트 소개 전용입니다.

## 🎯 컨셉

전국 축제를 단순 나열하는 앱이 **아닙니다**.
축제를 중심으로 **근처 관광지·맛집·숙소를 묶어 1박 2일 코스를 자동 생성**합니다.

> "5/3 보령 머드축제 → 근처 맛집 3곳 → 가성비 펜션 → 일요일 안면도 코스"
> 이런 일정을 한 번에 묶어서 보여줍니다.

## ✨ 핵심 기능

- **축제 탐색** — 지도 / 캘린더 / 리스트 3가지 뷰
- **코스 자동 생성** — 거리·카테고리 다양성·시간대 점수화 알고리즘
- **코스 저장 & 공유** — OG 이미지 자동 생성, 친구 초대
- **다녀온 기록** — 사진·메모로 만드는 개인 축제 다이어리
- **카테고리 알림** — 음악·푸드·꽃·불꽃 등 두 달 전 푸시 알림

## 🛠 기술 스택

- **Frontend** — Next.js 15 (App Router), Tailwind CSS
- **Backend** — Supabase (Auth · Postgres · RLS · Storage)
- **지도** — 카카오맵 SDK
- **데이터** — 한국관광공사 TourAPI 4.0 (KorService2)
- **인프라** — n8n 주 1회 동기화, Vercel 배포, Web Push (VAPID)

## 🧠 기술적 의사결정 하이라이트

- **TourAPI 일 1,000건 한도 → `nearby_places` 사전계산** — 외부 API 의존도 최소화
- **단일 `contents` 테이블 정규화** — 모든 콘텐츠 타입(축제·관광지·맛집·숙소)이 공통 스키마라 가능
- **코스 생성 알고리즘** — 거리 효율성 + 카테고리 다양성 + 평점 점수화
- **공유용 OG 이미지 동적 생성** — Next.js OG image API 활용
